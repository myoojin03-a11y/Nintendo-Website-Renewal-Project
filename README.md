### 🔍 Renewal Highlights

- 정보 위계가 분산되어 있던 기존 구조를 재정리하여 **콘텐츠 흐름을 명확하게 개선**
- 주요 콘텐츠와 CTA 영역의 시각적 우선순위를 조정하여 **사용자 집중도 향상**
- 섹션 간 여백과 레이아웃을 정리해 **가독성과 UI 일관성 강화**

## 📌 Project Overview

기존 닌텐도 웹사이트를 분석하여  
콘텐츠 구조와 UI 흐름을 개선한 웹사이트 리뉴얼 팀 프로젝트입니다.

사용자 경험을 중심으로 정보 위계를 재정리하고,  
퍼블리싱 관점에서 완성도 높은 UI 구현을 목표로 진행했습니다.

<br>

## 🎯 Project Goal

- 기존 닌텐도 웹사이트의 정보 구조와 UI 흐름을 분석하여 **사용자 경험을 개선**
- 주요 콘텐츠가 명확하게 전달되도록 **콘텐츠 위계와 레이아웃 재구성**
- 팀 프로젝트 협업을 통해 **역할 분담과 커뮤니케이션 경험 강화**
- 시맨틱 마크업과 일관된 스타일링을 적용하여 **퍼블리싱 완성도 향상**

<br>

## :people_holding_hands: Team & Role

## 📝 What I Learned

- 기존 웹사이트를 분석하고 리뉴얼 방향을 설정하는 과정에서 **콘텐츠 구조와 사용자 흐름의 중요성**을 이해하게 되었습니다.
- 팀 프로젝트를 통해 역할 분담과 협업의 필요성을 경험하며, **GitHub와 Slack을 활용한 협업 흐름**에 익숙해졌습니다.
- SCSS 구조화와 페이지별 스타일 분리를 통해 **유지보수를 고려한 퍼블리싱 방식**을 학습했습니다.
- 문제 해결 과정에서 AI 도구를 보조적으로 활용하며 **스스로 원인을 분석하고 해결 방향을 판단하는 역량**의 중요성을 느꼈습니다.
- SVG 태그에 대해 이해하게 되었고 `fill` 속성을 활용하여 아이콘의 색상을 제어하는 방법을 익혔습니다. (`active` / `inactive` 상태에 따라 SVG 아이콘의 컬러를 변경)
- 팀원들과 함께 프로젝트를 진행하며 협업의 중요성을 다시 한번 느낄 수 있었습니다. 작업 과정에서 서로의 의견을 공유하고 조율하는 과정을 통해 원활한 커뮤니케이션의 필요성을 배우게 되었고, 협업을 통해 더 나은 결과물을 만들어가는 경험을 할 수 있었습니다.
- SCSS를 사용하여 스타일 작업을 진행하면서 변수 선언 등 편리한 기능을 활용하는 방법에 익숙해질 수 있었습니다.  또한 팀 프로젝트에서 SCSS를 사용하면 스타일을 보다 체계적으로 관리할 수 있어 협업 시 효율적으로 작업할 수 있다는 점을 알게 되었습니다.
